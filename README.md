# Живая спектрограмма

Спектрограмма речи в реальном времени для уроков фонетики: говорите в микрофон, и речь рисуется как на спектрограмме из учебника (0–8000 Hz, время слева направо). Паузы автоматически отмечаются как короткие `|` и длинные `||`, звуки можно подписать символами IPA.

Работает в браузере на компьютере и телефоне. Ничего не устанавливается, запись никуда не отправляется.
